# Boss Health

The boss life bar shows the boss's **current health as a number** next to its name, updated live.

- Data only: changes nothing but the boss bar. No loader needed.
- Co-op: each player sees it on their own screen.
- Needs a mod manager CLI that supports the `label_format` content step (rsmm newer than 6.1.1). On an older one, apply stops with an "unknown step key" error. Update the app and apply again.
