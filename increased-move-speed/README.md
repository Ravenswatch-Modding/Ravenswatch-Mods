# Increased Move Speed

Choose **100%, 150%, 200%, or 500%** of your movement speed when the mod activates. The default is **200%**, which doubles your speed. The setting is available in the mod's settings in RSMM and changes take effect during the run.

Requires the RSMM loader and the experimental `R.stat.modify` SDK call. In-game behavior has not been verified for this release.
